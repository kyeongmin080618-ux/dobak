# 한 번만 더? — Vercel 배포

정적 웹 게임입니다. 빌드 명령이나 서버 함수가 필요하지 않습니다.

## Vercel에 배포하기

1. `index.html`, `style.css`, `wager.css`, `systems.css`, `game.js`, `vercel.json`과 이 README를 저장소 최상위에 올립니다.
2. Vercel에서 **Add New → Project**를 선택하고 저장소를 연결합니다.
3. Root Directory는 저장소 기본값(`.`)을 사용합니다.
4. Framework Preset은 **Other**, Build Command는 비워 두고, Output Directory는 `.`으로 설정합니다.
5. **Deploy**를 누르면 공개 웹 주소가 생성됩니다.

또는 저장소를 내려받은 뒤 프로젝트 폴더에서 `vercel --prod`를 실행할 수 있습니다.

세 명의 가상 참가자와 함께 진행하며, 매 라운드 보유 게임머니 범위에서 베팅액을 직접 정할 수 있습니다. 자금이 바닥나면 은행 대출, 신용 하락, 사금융, 상환 압박, 파산 선택으로 이어지는 교육용 흐름을 경험할 수 있습니다. 실제 돈이나 실제 사람과는 연결되지 않으며, 돌아보기 입력 내용은 저장하거나 전송하지 않습니다.
